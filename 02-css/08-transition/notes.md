# CSS Transition Notes

## Important Concepts & Tags

- `transition`: Shorthand for animating property changes over time.
- `transition-property`: Selects which CSS properties should animate.
- `transition-duration`: Controls how long the animation takes.
- `transition-timing-function`: Controls pacing, such as `ease`, `linear`, or `ease-in-out`.
- `transition-delay`: Waits before starting the animation.

## Common Mistakes

- Trying to transition properties that do not animate well.
- Forgetting to set both the starting and ending states.
- Making transitions too slow, which makes the UI feel sluggish.

## Interview Notes

- **What is the purpose of CSS transition?** It smoothly animates a property change from one state to another.
